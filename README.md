# Dino Runner: Atak Arbuzów

Offline'owy klon gry Dino z Chrome (skok/kucanie nad przeszkodami, rosnąca prędkość, wynik w `localStorage`), z jedną zmianą: po ~500 punktach kaktusy znikają i zamiast nich pojawiają się kolczaste arbuzy.

Otwórz `index.html` w przeglądarce — działa całkowicie offline, bez serwera.

## Sterowanie

- Spacja / Strzałka w górę — skok
- Strzałka w dół — kucnięcie
